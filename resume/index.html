요약

고객 현장에서 문제를 진단하고, 목표를 다시 정의하고, 운영되는 시스템으로 만드는 Forward Deployed Engineer입니다. 개발 · 전략 · 컨설팅을 한 사람이 끝까지 연결합니다.

  • Consulting — 요구사항을 다 구현하고도 목표를 놓친 ERP 프로젝트를 현장 재방문으로 다시 진단하고, "담당자가 실행하는 구조 → 결과만 승인하는 구조"로 목표를 재정의해 Phase 2로 전환.
  • Strategy — 핀테크에서 이탈 원인을 짚어 3-클릭 구독형 운용 상품을 기획·구축, AUM 500억 원+ · 서비스 매출 40% 기여. 사업부 FDE 역할 방향을 제안하고 채용 1차 면접관을 맡음.
  • Engineering — 레거시 ERP 운영 이관 2건(23,130라인 전량 일치), 1,600+ 계좌 24/7 분산 실행 인프라, Rust 전환으로 메모리 −95%.
  • AI — LLM이 직접 실행하지 않는 경계(계획 검증 · 사람 승인 · 읽기 평면)를 설계하고, 평가 세트 · 백테스트 · 셰도우 대조로 도입 속도를 데이터로 결정.

  • 소비재 브랜드 AI 데이터 워크스페이스 — FastAPI · Next.js · PostgreSQL · DuckDB · AWS ECS 단독 리드. LLM은 조회 계획만 만들고 서버가 검증·실행. 90문항 평가 세트로 모델 비교(81.1% / 87.8%, p = 0.070).

  • 에이전트용 헤드리스 접근 계층 — 해시 저장 API 토큰, 읽기 등급, 허용 컬럼 view 155개로 에이전트 읽기 범위 고정.
