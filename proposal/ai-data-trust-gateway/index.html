SECTION 0
한 줄 요약
TL;DR
당근의 data-mcp 확산으로 자연어 데이터 접근은 이미 빠르게 넓어지고 있습니다. 다음 병목은 “누구나 물을 수 있는가”가 아니라 “그 답을 믿을 수 있는가”라고 봅니다. 본 제안서는 KarrotMetrics, Lineage, BigQuery, Event, Experiment MCP 위에 지표 정의·권한·품질 상태·리니지·감사 로그를 응답과 함께 제공하는 AI Data Trust Gateway를 제안합니다. 단, 처음부터 모든 요청을 한 곳으로 모으기보다 파일럿 도메인과 고위험 요청부터 검증 가능성을 표준화하는 경량 신뢰성 컨텍스트 레이어로 시작합니다.

SECTION 3
문제 정의 — 셀프서비스는 확산됐지만 신뢰성은?

data-mcp 6종 도입으로 분석가·PM·마케터·엔지니어 누구나 자연어로 데이터에 질문할 수 있게 되었습니다. 동시에 새로운 위험이 동반됩니다 — "그럴듯하지만 틀린 답", "지표 정의 무시한 요약", "권한 범위를 넘은 응답". 이는 외부 자료에서도 직접 언급된 패턴입니다.

data-mcp 활용 흐름 — 접근·응답 확산 이후 응답 신뢰성 검증이 병목이 될 수 있음

이 가설은 외부 추정이므로 입사 후 검증이 전제됩니다. 데이터가치화팀은 이미 data-mcp 인증 체계 개선과 거버넌스 강화를 2026년 우선순위로 명시한 만큼, 본 제안서는 그 방향에 합류·가속하는 형태로 기여하는 것을 목표로 합니다. 더불어 KarrotMetrics가 이미 운영 중인 지표 결산·재계산 메커니즘과 User Activation 공통 데이터 레이어는 AI 응답의 신뢰 상태(결산 여부·신규/유지/복귀 분해 등)와 직접 연결될 수 있는 자산입니다.

SECTION 4
검증 계획 — 입사 후 30-60일

본 제안서의 가설은 공개 자료 기반의 외부 시각이므로, 입사 직후 다음 데이터를 수집해 우선 검증합니다.

  • →data-mcp 응답 신뢰성 패턴 — MCP 응답에 SLO·근거·소유권·최신성 메타데이터가 포함되는 비율, 사용자의 추가 검증 행동 빈도
  • →데이터 품질 이슈 영향 범위 — Lineage MCP 활용 사례에서 영향도 분석 소요 시간, 자동화 정도
  • →지표 정의 일관성 — KarrotMetrics 메타데이터에서 동일 의미 지표의 서비스별 정의 편차
  • →권한 범위 위반 패턴 — 사용자가 권한 외 데이터에 접근하려 한 사례, MCP의 차단·답변 거부 동작 일관성
분기점
가설이 강하게 확인되면 Phase 1 진행, 부분 확인이면 범위 축소, 다른 더 시급한 병목이 발견되면 즉시 우선순위 재정렬합니다. 본 제안서의 모든 단계는 데이터가치화팀의 검토와 동의 위에서만 진행됩니다.
SECTION 4.5
비목표 — 하지 않을 것

제안의 범위를 명확히 하기 위해, 의도적으로 제외하는 영역을 먼저 분리합니다.

  • →기존 KarrotMetrics, Data Catalog, Lineage 시스템을 대체하지 않습니다. 기존 source of truth를 존중하고, MCP 응답에 필요한 신뢰성 컨텍스트만 조합합니다.
  • →모든 데이터 요청을 처음부터 하나의 게이트웨이로 강제하지 않습니다. 파일럿 도메인과 고위험 요청부터 검증 패턴을 적용합니다.
  • →AI 답변이 항상 맞다고 전제하지 않습니다. 대신 지표 정의, 근거, 품질 상태, 권한 범위를 함께 제공해 사용자가 직접 검증할 수 있게 합니다.
  • →원천 데이터를 매 요청마다 재검증하지 않습니다. 사전 계산된 품질 메타데이터와 요청 시점 정책 검증을 결합합니다.
SECTION 5
솔루션 설계 — 3단계 진행
PHASE 1데이터 품질 SLO 정립 — 파일럿 도메인 1개 (1-2개월)
무엇을: 영향도가 큰 데이터 도메인 한 곳에서 4가지 품질 기준(가용성·최신성·완전성·정합성)를 정의하고 측정·모니터링 체계를 정착시킵니다.
어떻게:
  • ·도메인의 핵심 테이블·지표별로 4가지 품질 기준을 정량 목표로 정의합니다. 여기서 정합성은 일반적인 “정답률”이 아니라 도메인별 데이터 계약을 기준으로 한 validation pass rate로 제한해 정의합니다. 예: freshness p95 1시간 이내, schema validation pass rate 99.5% 이상, partition coverage 99.9% 이상, key uniqueness violation 0.1% 이하.
  • ·Project 03의 Quality Gate 패턴(row count · schema · key coverage · 값 범위 검사)을 적용해 SLO 위반을 자동 감지·알림합니다.
  • ·해당 도메인에 접근하는 MCP 응답에 SLO 메타데이터를 표준 필드로 함께 포함합니다(현재 SLO 충족 여부, 마지막 업데이트 시각, 오너).
  • ·산출물: SLO 정의서, 모니터링 대시보드, MCP 응답 메타데이터 명세.
PHASE 24가지 접근 방식의 데이터 신뢰성 영역 확장 (3-4개월)
무엇을: 이벤트 영역에서 검증된 4가지 접근 방식을 데이터 신뢰성 도구로 매핑합니다 — 기존 메타데이터·지표·리니지 source of truth를 대체하지 않고, MCP 응답에 필요한 신뢰성 컨텍스트를 조합·캐시하는 경량 계층입니다.
어떻게: 4가지 기준을 다음과 같이 매핑하며, AI Data Trust Gateway는 파일럿 도메인과 고위험 요청부터 검증 경로 역할을 합니다.

PHASE 3AI 데이터 접근 정책과 거버넌스 확산 (5-6개월)
